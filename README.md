# Практична робота №2 — Масиви (Python)

## Мета роботи

Ознайомитися з принципами роботи з масивами в мові програмування Python, навчитися використовувати цикли, умовні оператори, індекси та алгоритми обробки масивів.

Реалізувати 10 практичних завдань, використовуючи різні підходи до пошуку, сортування, зміни та аналізу елементів масиву.

## Використані алгоритми

У практичній роботі реалізовані:

- Лінійний перебір масивів.
- Метод двох вказівників.
- Пошук максимального значення.
- Перевірка парності.
- Обробка масивів на місці (in-place).
- Використання множин (`set`).
- Об'єднання відсортованих масивів.
- Прямий та зворотний прохід масиву.

## Висновок

У ході виконання практичної роботи було реалізовано 10 завдань на обробку масивів мовою Python.

Було закріплено навички роботи зі списками, індексами, циклами, умовними конструкціями та функціями.

Також було розглянуто алгоритми двох вказівників, пошуку, перестановки елементів та зміни масивів без створення додаткових структур даних.

Отримані знання дозволяють ефективніше працювати з масивами та розв'язувати алгоритмічні задачі.
